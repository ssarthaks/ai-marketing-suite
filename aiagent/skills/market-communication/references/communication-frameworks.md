## StoryBrand SB7 (Donald Miller) — the customer is the hero

The single most common communication mistake is making the brand the hero. Invert it:

| #   | Element                 | Rule                                                                                                                            |
| --- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **A Character**         | The customer (student/parent/school) is the hero, not the brand                                                                 |
| 2   | **Has a Problem**       | Name all three layers: External (the tangible obstacle), Internal (how it makes them feel), Philosophical (why it's just wrong) |
| 3   | **Meets a Guide**       | The brand is the guide — show **Empathy** ("we get it") + **Authority** (proof you can help)                                    |
| 4   | **Who Gives a Plan**    | A simple 3-step plan removes the fear of doing business with you                                                                |
| 5   | **Calls to Action**     | One **direct** CTA (Buy/Start) + one **transitional** CTA (download/free trial)                                                 |
| 6   | **Helps Avoid Failure** | Name the stakes — what they lose by not acting (loss aversion)                                                                  |
| 7   | **Ends in Success**     | Paint the transformed identity after using the product                                                                          |

**One-liner template:** _"Most [heroes] struggle with [problem]. [Brand] helps them [plan] so they can [success] — without [failure]."_

## Message Map Architecture

One core message, three pillars, proof under each. Everything the brand says must trace to a pillar.

```
CORE MESSAGE  (one sentence — the single, differentiated promise)
   ├── PILLAR 1  Functional / rational benefit   → proof, proof
   ├── PILLAR 2  Emotional / identity benefit     → story, outcome
   └── PILLAR 3  Social / community benefit        → testimonial, scale
```

Rules: exactly one core message (not five competing taglines); 2–3 pillars max; every pillar needs at least two proof points; if a planned asset can't be traced to a pillar, cut it or fix the map.

## Stakeholder Message Sheet (repeat per audience)

| Element                        | Fill in                              |
| ------------------------------ | ------------------------------------ |
| Primary concern                | What keeps this audience up at night |
| Core message for this audience | The pillar, said in their language   |
| Tone & voice                   | How it should feel                   |
| Key proof point                | The single most persuasive evidence  |
| CTA                            | The one action you want              |
| What NOT to say                | Off-limits claims/topics             |

Use the words the audience actually uses (mine Reddit/reviews) — not internal jargon.

## PESO Channel Model

| Type       | What it is                         | Strength                  | Watch-out               |
| ---------- | ---------------------------------- | ------------------------- | ----------------------- |
| **Paid**   | Ads, sponsored, paid influencer    | Fast reach, controllable  | Stops when budget stops |
| **Earned** | Press, organic mentions, reviews   | High trust                | Low control             |
| **Shared** | Social, UGC, community             | Scales engagement         | Needs constant feeding  |
| **Owned**  | Site, blog, email, app, press room | Full control, compounding | Slow to build           |

A healthy strategy uses all four with a clear role for each; over-reliance on Paid alone is fragile.

## Sticky Messages — Made to Stick (Heath brothers): **SUCCESs**

Simple · Unexpected · Concrete · Credible · Emotional · Stories. Pressure-test the core message against these six before locking it.

## Crisis Communication — DEARE

1. **Detect** — social listening, alerts; catch it early.
2. **Evaluate** — severity (contained vs. viral), root cause.
3. **Acknowledge** — public holding statement within 1–2 hours.
4. **Respond** — formal response on owned channels + outreach to affected parties.
5. **Evolve** — post-mortem, update protocol, transparency report if warranted.

**Tier the response:**

| Tier     | Trigger                                   | Response time | Owner       |
| -------- | ----------------------------------------- | ------------- | ----------- |
| 1 Low    | A single bad review/comment               | 24h           | Social team |
| 2 Medium | Viral post / media enquiry / data concern | 4h            | Comms lead  |
| 3 High   | Coverage / regulator / public backlash    | 1h            | CEO + Legal |

Holding-statement template: _"We've seen [issue] and are looking into it now. We'll share a full update within [X] hours."_
